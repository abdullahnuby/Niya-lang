# نية (NIYA) 0.2 — لغة برمجة

لغة برمجة كاملة (دوال، حلقات، قوائم، سجلات، closures، recursion، وحدات) بميزتين مش موجودين مع بعض في اللغات العادية:

1. **العقد جزء من الدالة**: `require` و`ensure` و`example` بتتكتب بين رأس الدالة وجسمها، وأمر `niya check` بيكسّرها بحالات حدود وعشوائية ويطلّعلك **مثال معاكس**.
2. **الأرقام بتعرف إنها تقديرات**: `21000 ± 15%` رقم حقيقي في اللغة، العمليات بتنقل المدى، والمقارنة غير الحاسمة **بترفضها** بدل ما تخمّن.

مكتوبة بـ Python كسقالة (أول تنفيذ لأي لغة بيتكتب بلغة موجودة). مفيش أي AI ولا مكتبات خارجية.

## التشغيل (اتجرّب على Python 3.13، ومتوقع يشتغل على 3.9 وأحدث)

```
python -m niya run examples/hello.nia          # شغّل برنامج
python -m niya check examples/quote.nia        # تحقق من العقود
python -m niya check examples/broken.nia       # كود بايظ: لازم يتمسك
python -m niya call examples/quote.nia quote 180 2 house
python -m niya repl                            # سطر أوامر تفاعلي
python -m unittest                             # الاختبارات (30)
```
كود خروج `check`: `0` متحقق، `1` فشل، `2` فيه جسم `{ ? }` فاضي. ملفاتك امتدادها `.nia` (UTF-8).

## جولة سريعة

```
let name = "عبدالله"                 # let ثابت، var بس هو اللي بيتغير
var total = 0
for i in range(1, 11) { total += i }
print("مجموع: {total}")              # {} جوه النص بتحسب تعبير

fn fib(n) => if n < 2 { n } else { fib(n - 1) + fib(n - 2) }   # if تعبير يرجّع قيمة
let shop = {name: "طيبة", items: ["شراب"]}                      # سجل
let more = set(shop, "items", push(shop.items, "تيشيرت"))       # القيم ثابتة: بترجّع نسخة جديدة
print(map([1, 2, 3], fn(x) => x * 2), area(h: 4, w: 5))        # مدخلات بالاسم
```
آخر تعبير في الجسم هو الناتج (أو `return`). الكلمات المفتاحية ليها مرادف عربي والاتنين مقبولين في نفس الملف.

| English | عربي | | English | عربي |
|---|---|---|---|---|
| `let` `var` | `ليكن` `متغير` | | `require` `ensure` `example` | `يشترط` `اضمن` `مثال` |
| `fn` | `دالة` | | `true` `false` `nil` | `صح` `غلط` `لاشيء` |
| `if` `else` | `لو` `والا` | | `and` `or` `not` | `و` `او` `ليس` |
| `while` `for` `in` | `طالما` `لكل` `في` | | `return` `break` `continue` | `ارجع` `اكسر` `كمل` |

الأرقام الهندية `٠-٩` و`،` `؟` و`٪` شغالة. دوال مدمجة بأسماء عربي: `اطبع طول مدى مجموع حول رشح اختزل اصغر اكبر قرب نص نوع مفاتيح قيم فيه هات ضع ضيف قطع رتب اعكس ضم قسم تاكد خطأ بصمة`. (راجع `examples/quote_ar.nia`.)

## العقود

```
fn quote(area: number in 30..1000, floors: int in 1..10, kind: "house" | "apartment") -> number
  require floors <= 10                      # شرط مسبق على المدخلات
  ensure result > 0                         # ضمان على الناتج (result أو ناتج)
  example (180, 2, "house") -> 1260000      # مثال
  example (area: 120, floors: 3, kind: "apartment") -> 1100000 ± 5%
{
  area * floors * rate[kind]
}
```
- **الأنواع**: `number int text bool list record any` (`رقم عدد نص منطقي قائمة سجل اي`) أو قيم مسموحة `"a" | "b"`، و`in lo..hi` للأرقام. بتتفرض **وقت التشغيل** على كل استدعاء، ومخالفتها `ContractError`.
- **`niya check`** بيشغّل الأمثلة، وبعدين بيجرّب حدود كل مدخل (min/mid/max) + 300 حالة عشوائية (seed ثابت، فنفس النتيجة كل مرة). مدخل نصه أو قائمته مش قابل للتوليد، فالدالة دي بتتفحص بالأمثلة بس.
- لو الدالة اتفحصت وطلعت سليمة بياخد **ختم** `@blake2b:...` على نص الدالة.
- جسم `{ ? }` معناه "لسه ما اتكتبش": `check` بيقول إنها ناقصة (مش بيدّعي إنها اتحققت)، وتشغيلها بيرفع `HoleError`.

## الأرقام غير اليقينية

```
let price = 21000 ± 15%        # أو 21000 +/- 15%  أو  21000 ± 500  أو  8..16
let total = price * 3 + 100    # [53550 .. 72450] بيتنقل تلقائياً
total.low   total.high   total.mid        # أحسن حالة / أسوأ حالة / المتوقع (ادنى اعلى متوقع)
total < 100000      # تمام لأن المدى كله تحت 100000 (true)
total < 60000       # خطأ: المقارنة مش حاسمة. اختار صراحة: total.high < 60000
```

## الدليل الكامل

- **جمل**: `let/var`، `x = ..` و`+= -= *= /=` (على var)، `if/else`، `while`، `for x in قائمة|نص|سجل`، `for a, b in أزواج`، `break/continue/return`، `use "ملف.nia"`.
- **أولويات**: `or` < `and` < `not` < المقارنة (مع التسلسل `1 < x < 10`) < `±` `..` < `+ -` < `* / // %` < `-` الأحادية < `**`.
- **شروط صريحة**: `if/while/and/or/not` بياخدوا صح/غلط بس (رقم أو نص = خطأ). مفيش truthy ضمنية.
- **قوائم/سجلات**: `xs[0]` `xs[-1]` `r.name` `r["name"]`. مفيش تعديل من جوه (`xs[0] = ..` غلط): استخدم `push` `set` `slice`.
- **دوال مدمجة**: `print len range sum map filter reduce min max abs round floor ceil sqrt str num int type keys values has get set push slice sort sort_by reverse join split upper lower trim replace enumerate zip any all assert error hash`.
- **حدود أمان**: حد للخطوات (`--fuel`) يوقف الحلقات اللانهائية، وحد لعمق الاستدعاء، ومفيش وصول لأي شيء من Python (التعبيرات بتتفسّر بالكامل جوه اللغة).
- **وحدات**: `use "lib.nia"` بتستورد كل الأسماء (اللي مش بتبدأ بـ `_`)، والأسماء ما بتتكررش في نفس المكان.

## مثال عالم صغير

## الحدود (بصراحة)

- **بطيئة**: تفسير على شجرة فوق Python. كويسة للمنطق والمقايسات، مش للحسابات التقيلة.
- **مفيش عالم خارجي لسه**: لا ملفات ولا شبكة ولا توقيع ولا BAB حقيقي. ده الخطوة الجاية (دوال `find/put/get/sign` + نقل رسائل).
- **الفحص مش برهان**: `check` بيلاقي أمثلة معاكسة لكن عدم لقاؤها مش معناه إنها مستحيلة (300 حالة مش كل الحالات).
- **الختم** على نص الدالة نفسها بس (مش الدوال اللي بتندهها)، وبـ blake2b مش blake3 (المواصفة بتقول blake3، ده المتاح في مكتبة Python).
- **`check` بينفّذ الكود اللي برّه الدوال** (وبيتجاهل مخرجاته). الدوال النقية (من غير `var` عامة) أنسب للفحص.
- **مفيش**: مولّد للثغرات `{ ? }` (ومقصود إنه مش AI)، أنواع معرّفة من المستخدم، pattern matching، try/catch، تعدد خيوط.
- أسماء المتغيرات بتتوحّد (أ إ آ ← ا، وبتتشال التشكيل)، لكن النصوص `"..."` بتفضل زي ما هي.
