# BAB wire v0.1: اللي اتنفّذ فعلاً

مواصفة الصيغة بتاعة `niya/wire.py` و`niya/world.py`. هي **جزء** من مسودة BAB-spec-v0.1 (ده اللي شغّال ومتجرّب).

## الهوية والقيم
- **الهوية:** `bab:ed25519:<64 hex>` = المفتاح العام (32 بايت). التوقيع Ed25519 (RFC 8032).
- **بصمة المحتوى:** `bab:blake2b:<64 hex>` = blake2b-256 على JSON ثابت للقيمة (مفاتيح مرتبة، من غير مسافات، UTF-8). (المسودة بتقول blake3.)
- **القيم على السلك:** JSON. الرقم غير اليقيني `{"$unc": [lo, nom, hi]}`. الدوال والأسرار **مبتتبعتش**. أسماء الحقول اللي بتبدأ بـ `$` محجوزة.

## الرسالة
إطار TCP: 4 بايت طول (big-endian) + JSON (حد 1MB). طلب واحد ورد واحد لكل اتصال.

```json
{"v":1, "verb":"CALL", "nonce":"<hex 16>", "time":1761600000.5, "to":"<id اختياري>",
 "cap":"quote.request", "args":{"area":180,"floors":2,"kind":"house"},
 "from":"bab:ed25519:…", "sig":"<hex 128>"}
```
`sig` = توقيع على JSON الثابت للرسالة بدون `sig` (وفيها `from`). الرد نفس الشكل: `verb:"REPLY"`, `to_nonce`, `status`, `data` أو `msg`.

**التحقق عند المستلم (بالترتيب):** صيغة v1 وفعل معروف ← توقيع سليم ← `to` (لو موجود) = هويتي ← `|time − now| ≤ 300s` ← nonce جديد (غير مستخدم). **العميل** بيتحقق من توقيع الرد و`to_nonce`، ولو ثبّت هوية (`expect`) من إن `from` = المتوقعة.

## الأفعال
| الفعل | args | الرد (`data`) |
|---|---|---|
| `ANNOUNCE` | `{manifest, ttl}` | `{stored:true}`. بيتخزن لو التوقيع سليم و`body.id = from`، ويتحوّل للجيران بـ ttl-1 (حد 3) |
| `FIND` | `{cap?, region?, tag?, deep?}` | قايمة مانيفستات موقّعة (حد 50). `deep` بيسأل الجيران كمان |
| `CALL` | سجل مدخلات القدرة `cap` | ناتج الدالة |
| `PUT` | `{value}` | `{cid}` (لو البوابة بتخزّن) |
| `GET` | `{cid}` | القيمة. العميل بيتأكد إن بصمتها = `cid` |

**الحالات:** `ok` · `refused` (مدخل أو شرط مسبق مخالف، قدرة مجهولة، توقيع/وقت/nonce غلط) · `error` (غلطة جوه البوابة نفسها: ضمان أو نوع ناتج اتكسر، أو الكود وقع).

## المانيفست (بيان البوابة)
قيمة موقّعة `{body, from, sig}`. الـ `body` بيتولّد من الدوال نفسها:
```json
{"id":"bab:ed25519:…", "name":"مكتب مزايا", "region":"luxor", "tags":["engineering"], "addr":"host:port",
 "caps":[{"cap":"quote.request",
          "takes":[{"name":"area","type":"number","lo":30,"hi":1000},
                   {"name":"kind","type":"enum","choices":["house","apartment"]}],
          "returns":"number", "ensures":2, "examples":2}]}
```
القدرة = دالة نية، والـ `takes` من توقيعها. مفيش بيان منفصل ممكن يتضارب مع الكود.

## لسه مش موجود
تشفير الرسائل، نموذج ثقة (`verified_by`/إلغاء)، حماية من السبام والإغراق، نقل غير TCP (Bluetooth/LoRa)، تخزين دائم للمحتوى، واجهة تتولّد من `takes` (Renderer)، وblake3.
